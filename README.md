# 歪瓜大奖赛 / WOBBLE GP

一个可在浏览器运行的街机赛车原型，支持 2–4 名真人局域网同场、玩家与三辆 AI 比赛，以及单车练习。第一张地图为「土豆环岛」，提供四款丑萌怪车，借鉴 Bruno Simon 的可驾驶玩具世界与街机卡丁车的轻松节奏；地图、名字、角色及界面为本项目创作。

## 本地启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run lan
```

这会构建游戏并启动 Node.js 联机服务器。主机打开 http://localhost:4173/，同一 Wi-Fi 的朋友打开终端输出的局域网地址（例如 http://10.15.39.238:4173/）。电脑 IP 可能随网络变化，请以启动时输出为准。

已经构建后，再次启动只需要：

```sh
npm start
```

主机需保持开机且服务器运行。联机服务和游戏网页共用 4173 端口。macOS 如果提示允许 Node 接受传入连接，请允许；访客 Wi-Fi 或校园网络的设备隔离可能阻止互访。

开发时另外运行 `npm run dev -- --port 5174`；Vite 将 `/ws` 代理到本机 4173 联机服务。`npm run preview` 仅预览静态页面，不提供联机后端。`dist/` 单独部署到静态托管可玩本地模式，真人联机还需要 Node.js 服务。不要直接双击 HTML。本次没有发布到公网。

## 真人同场怎么玩

1. 首页点击「和朋友联机」，填写称呼，创建房间。
2. 把 6 位房间码和局域网网址给朋友；也可复制带房间码的邀请链接。
3. 朋友点击联机并加入，或从邀请链接直接进入加入表单。
4. 每人选好怪车，点击「我准备好了」；换车会取消准备。
5. 至少 2 人、全员准备后，房主点击「全员发车」，统一倒计时后跑 3 圈。
6. 完赛者看到实时更新的结果；所有人完赛或退出后，房主可返回候场再开一局。

房间最多 4 位真人，不用 AI 补位。允许朋友选择同款车，车顶用名字区分。比赛中打开菜单只松开自己的油门，不暂停全场。掉线者记为退出 / 未完赛，房主掉线自动转交下一位在线玩家；当前不支持断线恢复本局，只能等候场重新加入。比赛期间不接受中途加入，每局最多 10 分钟。

## 部署到公网

当前联机代码是一个长连接 Node.js WebSocket 服务，前端静态页面和 `/ws` 必须从同一个服务提供。最省改动的免费方案是 **Render Free 单服务**：它执行 `npm ci && npm run build`，再执行 `npm start`；仓库已经附带 `render.yaml`。Render 免费实例会在无访问时休眠，第一次打开可能需要几十秒唤醒，适合朋友小范围试玩，不适合承诺全天在线。

你已有 Cloudflare 账户时，建议把 `race.ericproject.xyz` 作为游戏域名：在 Render 创建服务后，把该域名添加到 Render，Render 会给出验证用 CNAME；在 Cloudflare DNS 创建对应 CNAME 并打开代理（橙色云）。Cloudflare 会代理网页和 WebSocket，域名证书由 Render/Cloudflare 自动处理。NameSilo 只负责注册商；若域名 DNS 仍在 NameSilo，先把域名的 Nameserver 换成 Cloudflare 分配的两个 Nameserver，再在 Cloudflare 管理 DNS。不要删除现有 `@`、`www`、`hajimi` 等记录，新增 `race` 子域名即可。

Vercel 适合纯前端静态部署，不能直接承载当前 `/ws` 长连接；Cloudflare Pages 也只能承载前端。把前端放 Vercel、联机服务放 Render 会增加跨域、两个域名和 WebSocket 地址配置，当前版本没有必要。后续若要完全 Cloudflare 化，需要把 `server/room.ts` 改写为 Durable Objects，并单独处理房间持久化、限流、连接恢复和观测，代码量和测试面都会明显增加。

公网部署前请把 Render 服务的 `plan` 从 Free 升级或接受休眠限制，设置服务日志和健康检查；房间状态目前只在内存中，服务重启会清空房间，未提供账号、匹配、断线恢复或反作弊系统。

## 已实现

- 单车练习 / 四车大奖赛切换，其他三款怪车自动组成 AI 对手阵容。
- 局域网真人房间：建房、邀请码、准备、换车、统一倒计时、共享碰撞、排名、完赛与重赛。
- 手机驾驶：触屏按钮保留为默认方案；支持点击「手机倾斜」后用陀螺仪控制左右，油门、漂移和氮气仍用大按钮。
- 车库可选歪嘴小钢炮、暴走小土豆、卷王铅笔、迷路飞碟，显示实际模型预览并记住选择。
- 车模与碰撞尺寸统一缩至此前的 78%，跟车镜头稍微拉远，增加驾驶时的可见空间。
- AI 弯道减速、侧线避让、加速带、卡住恢复、车车碰撞与实时排名。
- 单张闭合赛道、3 圈比赛、8 个顺序检查点、圈速及本地最佳单圈。
- 加速、减速、倒车、惯性转向、空格刹车/漂移、氮气和路面加速带。
- 跳台、重力与落地、草地减速、障碍物碰撞、可推动路锥、离岛恢复。
- 薯币收集与氮气补充、轮子动画、漂移轮胎痕迹、扬尘、简易合成音效。
- 跟车/俯瞰镜头、赛道小地图、速度与氮气 HUD、键盘和触屏按钮。
- 切到其他窗口或打开说明时暂停，释放全部按键，避免失焦后车辆继续失控。
- 车模、字体、场景资源都在本地，不依赖在线素材 API。

## 技术选择

使用 **Three.js + TypeScript + Vite**。Three.js 负责 WebGL 场景、阴影和 GLB 模型；TypeScript 保持车辆、赛道和比赛数据边界清楚；Vite 提供开发和静态构建。

第一版车辆采用固定 60 Hz 的轻量街机运动模型，辅以圆形碰撞、速度投影和跳台高度函数。它服务于风格化驾驶，不是写实轮胎或悬架模拟。现阶段无必要引入完整的 Rapier 刚体车辆；若后续需要翻滚、推挤、动态平台、复杂车辆接触，再接入 Rapier 并保持现有输入与比赛接口。

- `src/track.ts`：赛道样条、路面、坐标、检查点路径和跳台参数。
- `src/vehicle.ts`：与视觉模型解耦的车辆状态和固定步长运动。
- `src/vehicle-dimensions.ts`：模型缩放与碰撞尺寸的共同基准。
- `src/kart-models.ts`：四款完整车型、轮子与悬浮动画、车库模型预览。
- `src/race.ts`：顺序检查点、圈数、计时和本地最佳记录。
- `src/world.ts`：场景、装饰、薯币、路锥与静态几何合批。
- `src/main.ts`：输入、渲染循环、镜头、UI、粒子与声音。
- `src/online-game.ts`：房间与结果 UI、服务器状态应用、真人车与排名显示。
- `src/network.ts` / `src/net-protocol.ts`：WebSocket 连接、输入发送、协议与状态类型。
- `server/room.ts`：权威比赛模拟；复用现有车辆、计圈和场景障碍布局。
- `server/index.ts`：静态文件、房间管理、WebSocket、心跳和连接清理。
- `public/assets/`：GLB 汽车、字体及相关许可。

调试接口 `window.__game` 只在开发模式存在，用于确定性地测试转向、跳台、计圈等；生产构建没有这个接口。

## 后续多车路线

1. **AI 对手（已实现）**：三辆 AI 复用车辆运动系统，沿赛道前视导航、减速转向及侧向避让；独立计圈、实时排名和终点用时排序。
2. **本地多车交互（基础已实现）**：车身前后双圆碰撞与对称冲量；后续可改进拥堵避让及难度，并按需要切换 Rapier。
3. **轻量道具**：先加入加速、护盾和路障，再考虑复杂投射物；使用原创造型与名称。
4. **网络多人（局域网基础已实现）**：60 Hz 服务器模拟、30 Hz 客户端输入、20 Hz 状态快照、客户端平滑显示。位置、碰撞、圈数和名次由服务器决定，不接受客户端提交成绩。后续可增加公网房间服务、断线重连和高延迟下的预测校正。

## 此轮反馈修复

- 修正 +Z 前向下的转向符号，←/A 左转，→/D 右转。
- 红白路肩改为沿每段内外弯的实际长度生成，消除重叠表面的深度闪烁。
- 改善相机深度精度、涂装 polygon offset 和车辆自阴影。
- 氮气耗尽使用滞回阈值，避免快速启停造成反馈闪烁。
- 合并静态场景绘制，减少 draw calls；提供不热更新的固定构建试玩地址。

## 验证与局限

TypeScript 检查及 Vite 生产构建通过；Playwright 浏览器检查覆盖实际按键驾驶及确定性车辆/比赛模拟，细项见 `QA.md`。

当前为桌面优先原型，并有响应式触屏控制。移动端布局与按钮已在浏览器模拟视口检查，尚未在真实手机 GPU 上实测。碰撞使用近似圆形，尚无车辆损伤、翻车物理或道具。联机面向可信局域网，不含账号、配对服务和互联网部署。游戏性能与主机模拟速度取决于设备负载和 WebGL 支持。

手机陀螺仪需要浏览器权限；iPhone 通常要求在 HTTPS 域名下由用户点击按钮授权。Render 的 `onrender.com` 已提供 HTTPS，因此可直接测试。横竖屏变化会自动读取合适的倾斜轴；若权限被拒绝，触屏方向键仍然可用。

手机进入比赛前会先显示方向准备页：点击允许传感器、保持当前姿势约 1 秒完成校准，再点击继续；也可以直接选择方向键。比赛中默认前进，镜头固定在车辆正后上方，左右倾斜方向与车辆视角一致。手机界面收起了桌面控制条和小地图，只保留速度、排名、油门、漂移、倒车、氮气和陀螺仪开关。

## 2026-09-10 四车版本

新增 `src/competition.ts`（AI 控制、碰撞、排名）和 `src/rival-visual.ts`（车型切换、动画与名字标签）。AI 圈速不写入玩家最佳记录。完赛的电脑车停靠路边，玩家完赛后显示名次和所有车手当时的状态。未完赛对手显示“尚未完赛”，不伪造其最终用时。
